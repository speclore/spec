# Examples

[core-project](core-project/README.md) is a complete valid core snapshot: root and collection
folders, contract and decision documents. The contract carries history, a typed dependency and
a body link. Its text attachment is an asset. Four derived records live in _refs.

Run the [validator](../conformance/README.md) against this project. Alternate positive and
negative examples are reproducible variations in [cases.json](../conformance/fixtures/cases.json).

GUID links require a SpecLore-aware viewer; plain Markdown still displays labels. Publication
documentation outside the example uses relative links and is not itself a conformant project.
