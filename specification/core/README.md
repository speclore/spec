# SpecLore 0.1.0-core

Status: release candidate specification. Profile identifier and release name: `0.1.0-core`.
The normative core contract is [core.md](core.md). The requirement checklist and executable
fixtures are in [conformance](../../conformance/README.md).

Core freezes document envelopes, folder descriptors, identity, links, relations, the derived
reference index and the observable guarantees of tools that mutate these artifacts.
The other domain documents are design background. They do not add requirements to this profile.

This repository is an editorial publication, not itself a conformant project tree. Its
relative publication links, schemas and release tooling remain ordinary repository files.
[The example project](../../examples/core-project/README.md) is the dogfooding target.
